# Projektbefehle

Diese Befehle liegen doppelt: hier als Projektbefehle (wirken sofort, für
jeden, der das Repository auscheckt) und in plugins/2fast4sale als
Plugin (zum Installieren über /plugin, falls sie einmal in mehreren
Projekten gebraucht werden).

Bei Änderungen beide Fassungen gleich halten — sonst tut derselbe Befehl
je nach Herkunft etwas anderes, und das merkt man erst, wenn ein Lauf
ein anderes Ergebnis liefert.
